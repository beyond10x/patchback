`--normalization`, each requiring the other (Da11-2); the statistics travel by path (Da11-3);
the library entry mirrors `StartFit` with an optional analysis and optional seed inputs, and
`fit` delegates to it (Da11-4); the refusals follow the spec's order with `AnalysisRequired`

(Da11-8); the seeded start replaces restart 0 (Da11-9); `run.meta` writes `init

only, format version 1 (Da11-10); a clamped prediction adds one warning line (Da11-11). For the
owner: the external mismatch marker and the missing `StartFit` refusal for a bad artifact
(Da11-5, Da11-6), the note span (Da11-8), the `run.meta` format bump (Da11-10), the § 11 flags
(Da11-2).
