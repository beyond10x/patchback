## Decisions

Da10-0 to Da10-15 in `approval-record:wave-a10`. The predictor is library-only (Da10-2),
takes the caller's normalized `features/1` values as `&[f64]` and casts them as the dataset
writer does (Da10-3), refuses in the order count, unknown, corrupt, mismatch, non-finite
(Da10-4, a recorded deviation from the spec's mismatch-before-corrupt), computes in `f32`
row-major (Da10-5), returns `raw`, clamped `values` and the clamp count with an in-memory
counter (Da10-6), refuses a NaN output as Rust-only (Da10-7), and is held to hand-computed
goldens, an `f64` reference and the pinned binary's `eval loss` (Da10-9). For the owner: the
`eval loss` reading if none matches (Da10-9), the Rust refusal order against the spec (Da10-4),
the carrier of `normalization.stats` to inference (Da9-9, a11 open point 3).
